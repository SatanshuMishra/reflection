# mjansson/mdns

Header-only mDNS/DNS-SD library. Public domain.

## Setup

Download `mdns.h` from: https://github.com/mjansson/mdns/blob/main/mdns.h

Or add as git submodule:
```bash
git submodule add https://github.com/mjansson/mdns.git windows/lib/mdns-upstream
cp windows/lib/mdns-upstream/mdns.h windows/lib/mdns/
```

This file will be added in Milestone 2 when the AirPlay core is integrated.
